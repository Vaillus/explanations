The boosting weight is paid token by token, before Whisper knows whether the keyterm will be completed. Many keyterms start with a token that also starts ordinary words: « Leclerc » starts with " Le", the French article at the head of a sentence. If the weight stayed, every hypothesis that writes « Le » and then any other word would keep it, and the search would favour hypotheses that start keyterms and never finish them. Withdrawal subtracts the boosting weights a hypothesis received for a keyterm it leaves incomplete, when its tree position falls back.

Each node of the prefix tree stores the boosting weight accumulated from the root to it. When the position falls back along a failure link, the score changes by the accumulated weight of the node it lands on minus that of the node it leaves, the rule the trace of section 7 applied. Falling back to the root withdraws everything. A completed keyterm keeps its weight: in TurboBias the node that ends a keyterm falls back at no cost.

At the end of the transcript

A hypothesis can also stop inside a keyterm: it writes « … le char Le » and then the end-of-text token. That token is not a child of any node, so if the end-of-text token is treated as one more transition out of the tree, the position falls back to the root and the weight is withdrawn on that token's score. The icefall library does this in ContextGraph.finalize, which subtracts the accumulated weight of the hypothesis's last position. In Whisper's beam search the extensions by the end-of-text token are sorted with the other extensions (section 5), so a withdrawal applied to the end-of-text token's score acts both when the hypothesis finishes and in the final ranking. Without it, a finished hypothesis keeps the weight of a keyterm it never completed.

The reverse problem exists too. In a model that, like Whisper, writes until it writes an end token, the boosting weights given to keyterm tokens can outscore the end-of-text token, and the model keeps writing keyterm tokens after the speech has ended. TurboBias adds to the end-of-text token's score, at each step, the largest boosting weight the tree can give, plus the weight of a keyterm just completed, so that ending the transcript stays competitive (Andrusenko et al. 2025, section II.C).
