A hypothesis's tree position stands for its current match: its last tokens, the ones that spell the path from the root to the position's node, so the start of a keyterm. At each decoding step the new token either continues that match, by a transition, or breaks it. This section is about the break, in one case: the tokens of the broken match end on the start of another keyterm. Sending the position back to the root would forget them, and that other keyterm would get no boosting weight. The failure link says where the position goes instead.

The position moves only once beam search has written the token, scored from the old position. On a break, the position drops the oldest tokens of the current match until what is left is a path from the root, then tries the token again from that node. The failure link of each node stores in advance where that dropping ends: the node whose path from the root is the longest ending of the node's own path. For rue·de, whose path is " rue" " de", that ending is " de", so the link points to de. When the token is still not a child at the node the link leads to, the position follows that node's failure link in turn, down to the root at most. Only the current match shrinks: the hypothesis keeps every token it wrote.

With failure links, the boosted tokens at a position are the children of its node and the children of every node its failure links lead to. That chain always ends at the root, which is why the children of the root are boosted from any position, and why " L" is already green at rue·de and wins the step that writes it.

Adding these links to a prefix tree is the Aho-Corasick algorithm (Aho and Corasick, « Efficient string matching: an aid to bibliographic search », Communications of the ACM, 1975), built so that every entry of a list is found in one pass over a text. The boosting-tree libraries of section 12 build their tree with it. Most failure links lead to the root, since a token that breaks a match usually starts no keyterm. The links to inner nodes matter when keyterms overlap, as street names sharing « de », « du » or « rue » do.
